### 소개

> **잔머리를 굴리는 사람, 김민우입니다!**

### 나의 이야기



진로라는 것을 고민하기 시작한 것은 고등학교를 진학하면서였습니다. 당시에 하고 싶었던 것은 연구였는데 막상 어떤 것을 연구하여야 하는지에 대하여 고민이 필요하였습니다. 도서관에서 책을 보다가 우연히 관심을 가지게 되었던 것은 '적정 기술'이라는 분야였습니다.  

적정 기술(Appropriate Technology)이란, 기술이 사용될 곳의 환경과 사용자에 초점을 둔 기술을 뜻합니다. 
최신의 기술은 아니지만 사용하는 사람의 삶을 최대한 고려한 기술입니다.   
사람은 혼자 살아가는 것이 아니라 여러 사람과 같이 살아갑니다.   
기술이 사람의 편의를 위해 발전하는 것은 맞으나, 여러 사람이 같이 살아가기 위한 기술에는 더욱 의미가 있을 것이라 생각했습니다. 

### 나의 강점
<details>
<summary>접근성 중심의 기술 고려</summary>
  제가 초등학교 때, 집에서 학교를 가는 길은 여러가지가 있었습니다.<br>  
  최단거리로 가는 방법이 있었고, 최대한 큰 길로 가는 방법, 자전거로 타고 가기에 좋은 환경의 길, 조용히 가는 길 등 여러 가지가 있었습니다.<br>  
  이러한 여러 가지 방법을 존재하게 한 것은 제가 접근하기 쉬운 방법을 찾아보고자 하는 것이었습니다.<br>  
  서비스는 결국 사람이 사용하기에 편리해야 합니다. 이것은 접근성과 연관이 있다고 생각합니다. 
</details>
<details>  
<summary>다양한 기술에 대한 유연성</summary>  
 제가 본격적으로 개발이라는 공부를 시작하게 된 것은 2024년도 졸업을 준비하면서였습니다.<br>
 이걸 작성하는 시점에도 거의 1년이 조금 지났습니다.<br>
 그 시간동안 여러 언어들과 프레임워크들을 접해보았습니다.<br>
 물론 깊고 넓게 알고 있는 것은 아니지만, 그래도 그 기술들을 접해보고 사용해보았습니다.<br>
 개발자는 기술을 배우고 사용하는 것이 중요하지만, 사용자에게 어떤 서비스를 제공하는지가 더 중요하다고 생각합니다.<br>
 서비스할 수 있는 수준까지만 기술을 배우고 더 심화적인 내용은 필요에 따라 배우고 사용하는 것이 효율적이라고 생각합니다.<br>
</details>
<details>
<summary>협업과 지식 공유</summary>  
  협업과 지식 공유는 개발자에게 중요한 요소입니다.<br>
  협업을 하면서 서로 지식을 공유하고 함께 성장하는 것이 중요하다고 생각합니다.<br>
  저는 협업을 하면서 서로 지식을 공유하고 함께 성장하는 것을 중요하게 생각합니다.<br>
</details>



### 사용해본 기술

- 프로그래밍 언어: Java, JavaScript, Python
- 프레임워크 및 라이브러리: Spring Framework, React
- 데이터베이스: MySQL, MongoDB
- 인메모리 데이터베이스: Redis
- 검색 엔진: Elasticsearch
- 메시징 플랫폼: Kafka, RabbitMQ
- 클라우드 서비스: AWS
- 컨테이너 및 오케스트레이션: Docker, Podman, Kubernetes
- CI/CD 도구: Jenkins, GitHub Actions
